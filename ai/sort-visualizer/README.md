# Sort Visualizer

## Overview
The Sort Visualizer is a web application that allows users to visualize various sorting algorithms through an interactive interface. Users can generate an array of random numbers, view them as bars, and see how different sorting algorithms sort these numbers with smooth animations.

## Features
- Generate an array of random numbers.
- Visualize the numbers as bars on the screen.
- Choose from multiple sorting algorithms:
  - Bubble Sort
  - Quick Sort
  - Merge Sort
  - Shell Sort
  - Selection Sort
  - Insertion Sort
- Adjust the animation speed for sorting visualizations.
- Responsive and appealing design.

## Getting Started
1. Clone the repository to your local machine.
2. Open the `index.html` file in your web browser.
3. Use the "Generate Random Numbers" button to create an array of random numbers.
4. Select a sorting algorithm and adjust the animation speed to visualize the sorting process.
